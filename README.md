# LiveHeader

LiveHeaderは、条件に一致するリクエストやレスポンスに任意のHTTPヘッダーを追加するChrome拡張機能です。

## 主な機能

- ヘッダー設定を名前付きのプロファイルで管理できます。
- リクエストヘッダーとレスポンスヘッダーを追加できます。
- URLパターンとHTTPメソッドで適用対象を絞り込めます。
- URLパターンでは `*` をワイルドカードとして使用できます。
- プロファイル、ヘッダー、フィルターを個別に有効・無効にできます。
- プロファイルの適用前にヘッダー名とURLパターンを検証します。

## 開発用インストール

1. Chromeで `chrome://extensions` を開きます。
2. **デベロッパーモード**を有効にします。
3. **パッケージ化されていない拡張機能を読み込む**を選び、このディレクトリを指定します。
4. ソースファイルを変更した後は、拡張機能のカードにある**再読み込み**を選びます。

## 使い方

ツールバーのLiveHeaderボタンを選ぶと設定画面が開きます。プロファイルを作成し、リクエストまたはレスポンスのヘッダーを追加してください。必要に応じてURLパターンやHTTPメソッドを設定すると、適用対象を限定できます。有効なフィルターがないプロファイルは、すべてのリクエストに適用されます。

プロファイルとヘッダー値はChromeのローカル拡張機能ストレージに保存されます。ヘッダー値は条件に一致した通信に付加されるため、送信先に渡してよい値だけを設定してください。

## パッケージの作成

Bashと`zip`コマンドが必要です。

このディレクトリで次のコマンドを実行します。

```bash
bash package.sh
```

`dist/LiveHeader.zip` に拡張機能のパッケージが作成されます。ZIPの直下に `manifest.json` が配置され、Gitの管理情報やREADMEなどは含まれません。

## 権限について

- `declarativeNetRequest`: 条件に一致するリクエストやレスポンスのヘッダーを変更します。
- `storage`: プロファイルや設定をChrome内に保存します。
- `<all_urls>`: すべてのウェブサイトをフィルターの対象にできるようにします。ヘッダーの変更は、有効なプロファイルとフィルターの条件に従って適用されます。
